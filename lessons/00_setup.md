# Lesson 00 — Setup and safety

## Goal

Create or open the approved GoFa RobotStudio station and start its virtual controller.

## Before you begin

- A recent version of RobotStudio is installed.
- Install the same version of RobotWare as the one in the real robot.
- You have read [Safety](../SAFETY.md).

## Procedure

1. Follow [RobotStudio station setup](../robotstudio/student/create-virtual-controller.md).
2. Start the virtual controller.
3. Confirm that the controller is running and the robot is visible in the station.
4. Import the Lesson 01 RAPID module using [the import guide](../robotstudio/student/import-rapid-modules.md).
5. Do not alter network or EGM settings in this lesson.

## Checkpoint

You can identify the active tool, workobject, robot base, and virtual controller state.
