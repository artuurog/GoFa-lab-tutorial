# Real-robot commissioning checklist

Complete this checklist with the instructor after the virtual-controller path succeeds.

- [ ] RobotWare and RobotStudio versions match the compatibility record.
- [ ] Correct tool and workobject have been verified.
- [ ] All RAPID targets are instructor-validated for this station.
- [ ] TCP endpoint is the approved real-robot endpoint.
- [ ] EGM reference pose and bounds are validated.
- [ ] Motion speed is appropriate for supervised teaching.
- [ ] Stop procedure has been reviewed and tested as approved.
- [ ] The area is clear and the operator mode is approved.
