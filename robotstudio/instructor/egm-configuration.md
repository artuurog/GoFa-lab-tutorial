# EGM configuration

## Instructor-only task

Configure and validate EGM using the exact RobotWare 7.x and RobotStudio versions recorded in [Compatibility](../../COMPATIBILITY.md). This guide intentionally does not provide generic, copy-paste configuration values: EGM parameters must be tested for the specific station.

## Before students run the EGM script

1. Confirm the EGM option and configuration model available on the controller.
2. Configure the approved EGM endpoint and record it outside version control.
3. Define one validated reference pose and bounded positional or joint limits.
4. Validate the trajectory in the virtual controller.
5. Test the approved stop behavior.
6. Review the real-robot checklist with the students.
