# Create the virtual controller

Use the instructor-approved RobotStudio and RobotWare versions listed in [Compatibility](../../COMPATIBILITY.md).

1. Open the station supplied for the lab, or create the approved GoFa station template.
2. Create a virtual controller with the specified RobotWare version.
3. Start the virtual controller.
4. Confirm that the robot model and controller state match the instructor’s reference.
5. Record no IP address or EGM changes in this student-facing procedure.

If any screen or option differs from this guide, stop and compare the installed versions with the compatibility record before continuing.
