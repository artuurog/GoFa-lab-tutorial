# Compatibility

## Supported baseline

| Component | Baseline | Record before teaching |
| --- | --- | --- |
| Robot | ABB GoFa | Exact robot type and payload configuration |
| Controller | OmniCore | Controller type and network interface used |
| RobotWare | 7.x | Exact major, minor, and patch version |
| RobotStudio | Recent release compatible with the chosen RobotWare | Exact installed version |
| Python | To be selected for the lab image | Version and operating system |

## Why exact versions matter

The RobotWare patch level and RobotStudio version can affect the available configuration screens, option names, and EGM setup details. Before publishing a runnable EGM configuration, record the exact versions in this table and test every instruction against the virtual controller.
